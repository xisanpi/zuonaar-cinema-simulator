# 数据来源与署名

## 主要影院数据源

- 作者：ArvinTing
- 数据表：[《全球 IMAX 及特效影厅分布》](https://docs.qq.com/sheet/DQ3FEUUZJdklNSWJP)
- 本次采用版本：2026-08-01
- 使用范围：影院名称、银幕宽高与面积、座位容量、IMAX / Dolby Cinema 等放映系统信息
- 本次匹配：以放映制式和规范化影院名称作唯一精确匹配，共核对 259 个影厅；多版本长宽取最后一组完整数值，面积缺失或与长宽明显不一致时按长宽重算

源表说明的可信度顺序依次参考银幕架、激光测距、银幕幕布、LF Examiner、影院官方宣传和网传数据。它是一份持续维护的社区数据集，不等同于影院或设备厂商的官方测绘；同一影厅在不同时期更换幕布后，也可能出现多组历史尺寸。

## 补充数据

尚未与主要数据源唯一匹配的影院继续沿用项目原有公开数据库；真实座位网格来自已抓取的猫眼选座页面。座间距、排距、高差、第一排距离与建筑结构仍为几何估算。
